## 2026-11-12 — Tăng độ tin cậy luồng deploy (rollback, commit rỗng, pull ff-only)

- **Bối cảnh:** Khi `add`/`commit` lỗi sau khi đã ghi file CICD, repo bị bẩn và lần sau lại stash tiếp; `git pull` có thể tự merge hoặc để repo ở trạng thái conflict; `commit` không có thay đổi chỉ báo "Git commit failed" chung chung; `rev-parse` chạy ngoài `runGit` (không timeout/log).
- **Quyết định (người dùng chọn):** (B5) `rev-parse` đi qua `runGitOutput` (timeout, log, `GIT_TERMINAL_PROMPT=0`), lỗi -> `Git rev-parse failed`. (B3) `git pull --ff-only` kèm dòng log gợi ý. (B2) sau `add`, không có thay đổi staged -> dừng với `Nothing to commit`. (B1) lỗi sau khi ghi file CICD và trước khi commit xong -> `git checkout HEAD -- <file>` best-effort; commit đã tạo mà push lỗi -> không rollback, chỉ log commit còn local.
- **Phương án đã cân nhắc:** B1: chỉ ghi log hướng dẫn, hoặc giữ nguyên (bỏ vì để repo bẩn). B2: bỏ qua commit và vẫn push (bỏ vì có thể đẩy commit cũ chưa push lên pipeline ngoài ý muốn). B3: giữ pull mặc định và chỉ cải thiện log (bỏ vì vẫn có thể kẹt trạng thái merge). Reset commit khi push lỗi (bỏ, quá phá huỷ).
- **Lý do:** Đưa repo về trạng thái sạch khi lỗi ở bước có thể hoàn tác an toàn, không đụng vào commit đã tạo. `hasStagedChanges` không đi qua `runGit` vì exit code 1 của `git diff --cached --quiet` là kết quả bình thường. Cờ `cicdWritten` chỉ đặt sau khi `updateCICDFile` trả về, nên khi file CICD không tồn tại thì không rollback (tránh vô tình khôi phục file bị xoá).
- **Thay đổi hành vi cần biết:** log có thêm dòng `$ git rev-parse ...` và `$ git diff --cached ...`; lỗi rev-parse đổi thông báo; `--ff-only` làm fail các ca trước đây tự merge hoặc rebase (kể cả khi cấu hình `pull.rebase`); nhánh local có commit chưa push (từ dry-run hoặc push lỗi lần trước) sẽ làm pull fail nếu remote đã tiến. Rollback có thể thất bại khi file CICD untracked/gitignore hoặc còn `index.lock`; khi đó chỉ log để kiểm tra tay. `git stash` vẫn không pop, giữ nguyên hành vi cũ. Bổ sung sau review: mọi lệnh git đặt `GIT_LITERAL_PATHSPECS=1` để tên file CICD như `CICD[1].txt` không bị hiểu là glob/magic (trước đây `git add` có thể khớp thêm file khác); dòng gợi ý khi pull lỗi nêu thêm nguyên nhân mạng/xác thực. Chưa xử lý (có từ trước): `updateCICDFile` dùng `path.join` còn bước kiểm tra dùng `path.resolve`, và `startsWith('..')` từ chối nhầm tên file bắt đầu bằng `..`.
- **Liên quan:** `src/main/deploy-service.ts`, `tests/deploy-service.test.ts`, `AGENTS.md`
